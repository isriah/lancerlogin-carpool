# LancerLogin Carpool plugin v1.0.0

This first standalone release packages Carpool as a LancerLogin module plugin. It contains the same Carpool that was part of LancerLogin 2.0.0-beta.11, so an installation that already uses Carpool keeps its plans, people, groups, settings, meeting links and permissions unchanged when it selects this release.

## Bugs fixed

None.

## Features added

- Carpool is available as a separately selected plugin for LancerLogin Modular 2.0.0-beta.11 and later 2.x releases.
- Carpool adopts the database tables LancerLogin already created, so selecting the plugin runs no database change on an existing installation.

## Features removed

- Carpool no longer reads the `CARPOOL_GEOAPIFY_KEY` deployment variable, because plugins never receive the installation's Worker environment. Save the Geoapify API key in **Settings > Modules > Carpool** instead. A key already saved there keeps working.
