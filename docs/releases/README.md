# Release notes

Every stable or beta release tag has a matching `vX.Y.Z.md` or `vX.Y.Z-beta.N.md` file in this directory. The release is published with it as the GitHub release body. Start with a plain-English summary, followed by Bugs fixed, Features added and Features removed. Include update or repair instructions only when specific user action is required. Nightly builds have generated notes and no file here.
