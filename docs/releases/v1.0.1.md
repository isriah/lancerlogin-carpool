# LancerLogin Carpool plugin v1.0.1

This release changes nothing in Carpool itself. Installations that select it keep their plans, people, groups, settings, meeting links and permissions exactly as they are, and selecting it runs no database change. It supports the same LancerLogin Core versions as v1.0.0: Modular 2.0.0-beta.11 and later 2.x releases.

What changed is how the plugin is checked and described. Every change to the plugin is now verified against the public LancerLogin Core repository, with no private access needed, and the README now describes the plugin as public, so installations can fetch it without a token.
