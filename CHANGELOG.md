# Changelog

All notable changes to the LancerLogin Carpool plugin. Versions follow LancerLogin's release rules: stable `X.Y.Z`, beta `X.Y.Z-beta.N`. Testing-only nightly builds (`X.Y.Z-nightly.YYYYMMDD`) are not listed here; their GitHub prereleases list their commits. Full patch notes for each release are in [docs/releases](docs/releases/README.md).

## [1.0.0] - 2026-10-26

This first standalone release packages Carpool as a LancerLogin module plugin. Supports LancerLogin Core `>=2.0.0-beta.11 <3.0.0`. See [v1.0.0](docs/releases/v1.0.0.md).
